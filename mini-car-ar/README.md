# Mini Car Showroom AR



## What my project has

* A Hiro marker scene with a floor, cylinder stand, car, ball, box, cone and a text label.
* Two animations: the car rotates and the ball moves up and down.
* A real 3D Toy Car model (not the workshop duck).
* Tap the ball to change its colour.
* Tap the orange box to change its size (my extra interaction component).
* A banner changes from red to green when the marker is detected, and back to red when it is lost.



## How to run

1. For a phone, publish this folder using **GitHub Pages** or **Netlify Drop**.
2. Open the **HTTPS** link on the phone using Safari or Chrome.
3. When the phone asks to use the camera, tap **Allow**.
4. Print a **Hiro marker** or show it on another device and point the camera at it.
5. Tap the coloured ball and orange box to try the interactions.
